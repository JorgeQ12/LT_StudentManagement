# AWS Architecture Icons

Estos SVG fueron extraídos del paquete oficial **AWS Architecture Icons**, versión publicada el 30 de abril de 2026.

Fuente: <https://aws.amazon.com/architecture/icons/>

Se conservan únicamente los servicios utilizados en la arquitectura de Student Management. Los mismos SVG están incrustados como imágenes dentro de `student-management-aws-architecture.drawio`, por lo que el diagrama puede abrirse y compartirse sin depender de rutas locales.

Los nombres, marcas e iconos de AWS pertenecen a Amazon Web Services, Inc. o sus afiliadas y se utilizan exclusivamente para documentar la arquitectura desplegada.
